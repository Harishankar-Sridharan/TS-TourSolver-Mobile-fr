# Annuler

### 1. Prise en main

Veuillez noter que les sources fournies se concentrent spécifiquement sur le processus d'annulation d'intervention. Par conséquent, des informations détaillées concernant les exigences système, l'installation, les étapes de configuration ou la configuration initiale de l'application TourSolver Mobile ne sont pas disponibles dans ces sources. Vous devrez peut-être consulter une autre documentation pour ces étapes initiales.

### 2. Annuler une intervention

Le **Annuler une intervention** fonctionnalité vous permet de révoquer une intervention que vous avez précédemment confirmée. Cela est particulièrement utile si vos plans changent de manière inattendue ou si une intervention n'est plus nécessaire après son démarrage. En suivant quelques étapes simples, vous pouvez vous assurer que votre planning est exact et que toute intervention inutile est rapidement supprimée.

### 3. Comment annuler une intervention

Cette section fournit un guide étape par étape pour annuler avec succès une intervention dans TourSolver Mobile.

**Scénario :** Vous avez démarré une intervention et l'avez confirmée, mais vous devez maintenant l'annuler en raison d'un changement de plans ou de circonstances.

#### **Instructions étape par étape**

1. **Commencer l'intervention (prérequis)** Avant de pouvoir annuler une intervention, vous devez d'abord la commencer.
   *   Appuyez sur **Commencer** pour démarrer l'intervention.

       <figure><img src="../.gitbook/assets/Media (9).jpg" alt="" width="375"><figcaption></figcaption></figure>
2. **Confirmer l'intervention** Après avoir appuyé sur « commencer », une fenêtre de confirmation apparaîtra. Vous devez confirmer l'intervention pour continuer.
   * Une fenêtre de confirmation apparaît.
   *   Appuyez sur le **bouton vert de confirmation** sur cette fenêtre pour confirmer l'intervention.

       <figure><img src="../.gitbook/assets/Media (11).jpg" alt="" width="375"><figcaption></figcaption></figure>
3. **Lancer l'annulation** Une fois que vous avez confirmé l'intervention, si vous décidez de l'annuler, recherchez l'option d'annulation.
   *   Appuyez sur le **bouton rouge d'annulation** situé en bas de votre écran. Cette action lance le processus d'annulation.

       <figure><img src="../.gitbook/assets/Media (13).jpg" alt="" width="375"><figcaption></figcaption></figure>

       * _(Veuillez noter : Ce guide ne peut inclure de segment vidéo direct ni de GIF, mais cette étape implique généralement une brève animation montrant l'appui sur le bouton.)_
4.  **Confirmer l'annulation** Pour éviter les annulations accidentelles, le système vous demandera une confirmation finale.

    * Une nouvelle fenêtre de confirmation apparaît.
    * Appuyez sur le **bouton vert de confirmation** sur cette fenêtre pour finaliser l'annulation.

    <figure><img src="../.gitbook/assets/Media (10).jpg" alt="" width="375"><figcaption></figcaption></figure>
5. **Vérifier la réussite de l'annulation** Après avoir confirmé l'annulation, l'application affichera un message indiquant le résultat de votre action.
   *   Vous verrez un message confirmant que **"Statut rétabli à accepté avec succès"**. Cela confirme que l'intervention n'est plus active.

       <figure><img src="../.gitbook/assets/Media (12).jpg" alt="" width="375"><figcaption></figcaption></figure>

### 4. Astuces de productivité

💡 **Toujours confirmer :** Après avoir lancé une action, en particulier des annulations, recherchez toujours le message de succès. Cela garantit que votre action a été correctement enregistrée par l'application et apporte une tranquillité d'esprit.

⚠️ **Agir rapidement :** Si vous réalisez qu'une intervention doit être annulée, il est préférable de le faire dès que possible après sa confirmation initiale. Cela aide à maintenir la précision de votre planning et évite tout suivi inutile.

Nous espérons que ce guide vous aidera à gérer vos interventions en toute confiance dans TourSolver Mobile !
