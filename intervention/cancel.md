# Annuler

### 1. Prise en main

Veuillez noter que ce guide se concentre spécifiquement sur la fonctionnalité « Annuler l'intervention ». Les informations concernant les exigences système, les étapes d'installation ou la configuration initiale de TourSolver Mobile ne sont pas disponibles dans les sources fournies \[i, j].

### 2. Comprendre les interventions et l'annulation

Dans TourSolver Mobile, une « intervention » désigne une tâche ou une activité que vous devez accomplir. Parfois, les circonstances changent et vous pouvez avoir besoin d'annuler une intervention que vous avez commencée ou que vous étiez sur le point de commencer. Ce guide vous expliquera les étapes simples pour le faire.

### 3. Annuler une intervention

Avant de démarrer une nouvelle intervention ou d'annuler une intervention existante, il est crucial de vous assurer que vous avez terminé toutes les interventions actuellement marquées comme « en cours ». Vous devez finir toutes les interventions en cours avant de passer à la suivante.

Voici comment abandonner une intervention dans TourSolver Mobile :

1. **Accéder à l'intervention depuis votre tableau de bord**
   * Pour commencer, vous devez ouvrir l'intervention spécifique que vous souhaitez abandonner.

<img src="../.gitbook/assets/Intervention-Abandon_timestamp_0_to_00–0_to_18 (1).gif" alt="" width="360">

2\. **Trouver et appuyer sur le bouton d'abandon** \* Une fois que vous avez ouvert l'intervention, si vous décidez de l'annuler, recherchez le bouton dédié.

<img src="../.gitbook/assets/Media (9) (1).jpg" alt="" width="375">

3\. **Confirmer l'annulation**\* Après avoir appuyé sur le bouton d'annulation, une fenêtre contextuelle apparaîtra à l'écran pour confirmer votre action. Il s'agit d'une mesure de sécurité pour éviter les abandons accidentels.

<img src="../.gitbook/assets/Media (15).jpg" alt="" width="375">

4\. **Vérifier l'annulation**\* Une fois que vous confirmez, le système traitera votre demande.

<img src="../.gitbook/assets/Media (14).jpg" alt="" width="375">

### 4. Astuces de productivité

Des conseils spécifiques de productivité au-delà du processus « Annuler l'intervention » ne sont pas fournis dans les documents sources de ce guide \[i, j]. Cependant, utiliser efficacement la fonction « Annuler » comme décrit ci-dessus aide à maintenir votre tableau de bord ordonné et reflète avec précision votre charge de travail actuelle.
